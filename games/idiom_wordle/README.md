# 猜成语 Wordle 开发说明

## 模块边界

`core.py` 负责初始化、猜词、拼音匹配和状态转换，不导入 AstrBot，不执行消息发送。
`resources/idioms.json` 是从 Handle 源文件生成的 29,760 条成语及数字声调读音。
每局答案从该词库选择；猜测必须是该词库已收录的四字成语。
同长度输入未收录时返回 `not_idiom`，消息端固定回复 `xxxx 不是成语呢~`，不计次、不续时。
输入长度与答案不一致时消息端直接忽略，不提示、不计次、不续时。
词库拼音覆盖自动转换结果；相同汉字采用答案读音，参考 Handle。

## 时间与规则

最多 10 次有效猜测；非成语及重复猜测不计次、不续时。`now` 由调用方注入单调时钟。
开局截止时间为 `now + idle_seconds`，有效猜测后重新设置为 `now + idle_seconds`；默认 300 秒。
仅有一个空闲截止时间，不设整局上限。到达截止时间的猜测不受理。
超时检查与猜词提交必须使用同一个时间点，避免两次取时跨过截止时间造成误判。
四个汉字完全一致才能获胜；汉字、拼音部件、声调独立给出匹配提示。

2. 本地图片与 CLI，检查字体、颜色、尺寸及完整棋盘。
3. 统一游戏管理器与 AstrBot 路由，验证隔离、互斥、超时和卸载。

## 图片与调试入口

`render.py:render_board(game)` 接受游戏对象，返回 PNG 字节，不修改状态。
棋盘只绘制方框、汉字和分色拼音，不包含标题、行号、规则、图例或底部说明。
开局未猜词时显示一行空框；进行中按有效猜测逐行展示，最多十行。
主动结束、超时或十次未猜中时，在历史记录后追加全绿答案行（最多十一行）；
答案行不写入 `guesses`，不占用机会、不影响计时。没有猜测时只绘制答案行。
猜中时保留已有正确行，不重复追加。规则通过开局文字消息说明。
字体固定使用 `resources/fonts/NotoSansCJKsc-Regular.otf`（SIL OFL 1.1），无需系统中文字体。
`python -m games.idiom_wordle --answer 一心一意 --guess 画蛇添足 --output /tmp/board.png`
可在没有 AstrBot 的环境中生成图片。省略 `--guess` 进入交互模式。
CLI 在输入时检查超时；主动超时通知由插件后台调度实现。

## 插件接入与扩展

根目录 `game_manager.py` 只管理聊天范围及活动游戏，不依赖本游戏。
添加新游戏时创建新的 `games/<game_id>/`，保留本游戏接口边界，注册开始命令前检查统一管理器。
群内任何人可提交猜词和结束游戏，参与者共享次数。
聊天范围由平台实例 ID、群/私聊类型、群 ID 或私聊用户 ID 组成。
不要直接使用可能按群成员拆分的消息会话 ID 作为游戏键；通知路由仍使用 `unified_msg_origin`。

`main.py` 中每个聊天使用异步锁，涵盖判定、绘制及发送，保证棋盘顺序。
后台扫描截止时间，各群独立发送超时通知；回调验证 Session 身份，防止误删新局。
超时通知或图片发送失败会记录异常；已受理猜测不回滚、不再次计次。
游戏进行中绘图失败时提供文字汉字提示并保留进度。
主动结束、超时、十次失败与猜中统一使用棋盘图片展示答案，文字仅说明结束原因。
终局图片生成失败时只报告错误并释放游戏，不改用文字公布答案。
主动超时通知同样发送终局棋盘，使用与普通回复相同的图片构建逻辑。
活动游戏不持久化，卸载取消后台任务并清空状态。

## 验收清单

- 自动测试：非成语提示且不计次/不续时；重复字/部件/声调、多音字、同音不同字、10 次边界、截止时间等号边界。
- 时间测试注入 `now` 或时钟，不等待五分钟，不设置第二个整局计时器。
- 图片测试：PNG 可读、最多十行猜测加一行答案；仅绘制字和拼音；结束才公开答案；猜中不重复答案行。
- 人工检查进行中、主动结束和十次失败的真实图片，验证中文字体、拼音布局与答案行位置。
- 管理器/接入测试：跨平台/跨群/私聊隔离、同群共同猜题、并发开始、旧回调、通知失败与卸载。
- 真实宿主：插件加载、非 @ 群猜词、图片发送、主动超时通知、重载后可重新开始。

当前自动测试使用 AstrBot 替身，不代表真实平台已联调通过。

## 词库同步流程

`resources/handle/` 保存同一上游 commit 的 `idioms.txt` 与 `polyphones.json`，
版本、校验值、作者和许可记录于该目录 `SOURCES.md`。
`update_dictionary.py` 提供独立 Python 转换函数及离线生成入口：

```sh
.venv/bin/python -m games.idiom_wordle.update_dictionary
.venv/bin/python -m pytest games/idiom_wordle/tests -q
```

生成时合并两份互不包含的词库，排序去重，自动生成普通读音，优先采用上游多音字读音，
最后应用 `resources/pronunciation_overrides.json`。缺省声调补为轻声 5。
生成前校验全部词条和读音；错误会中止，不静默删除词条。
默认词库全部参与随机出题，生僻词难度会高于原来的 30 词版本。
普通读音未经逐词人工校对；修正写入覆盖文件后重新生成，避免下一次同步覆盖。
词库更新测试检查全部上游词条均已收录、多音字、轻声以及本地覆盖优先级。
保留上游源文件与许可，记录固定 commit、校验值和生成器依赖版本；从本地快照离线生成，
不要直接修改生成的 `resources/idioms.json`。

## 已知线索汇总

`hints.py:get_hint(game)` 独立汇总历史猜测中的绿色线索，返回每个位置已确认的汉字、
声母、韵母和声调；未知字段为 `None`，显示时替换为 `?`。
`format_hint(game)` 提供可本地调用的文字版本。
该操作只读取已公开的历史反馈，不读取隐藏答案读音、不增加猜测、不改变截止时间。
黄色线索尚不能确定位置，不填入对应位置；空声母的自动绿色标记不代表已确定零声母。
汉字正确时可汇总该次反馈已经显示的完整读音，轻声 0 显示为 5，已确认的空声母不显示问号。

`/猜成语提示` 在当前聊天中发送 `render.py:render_hint(game)` 生成的一行提示图片，
已知线索为绿色，未知汉字、声母、韵母、声调分别用 `?` 占位。
命令不计次、不续时；没有游戏时提示，超过截止时间则按正常超时结束，不额外泄露线索。
图片失败时退回 `format_hint(game)` 文字版本，同样只含已公开信息。


## AstrBot 超时配置

根目录 `_conf_schema.json` 注册 `idiom_idle_timeout_seconds`，在 AstrBot 插件配置中显示为
“猜成语有效猜词间隔（秒）”。默认 `300.0`，接受正数和小数，例如 `150` 为 150 秒、`2.5` 为 2.5 秒。
设置零、负数、非数字或非有限值时记录警告并回退为默认 300 秒。
配置接入遵循 [AstrBot 插件配置文档](https://docs.astrbot.app/dev/star/guides/plugin-config.html)。

开局时读取以秒为单位的配置，保存为 `IdiomGame.idle_seconds` 并固定于该局；有效猜测按同一间隔续时。
修改配置对新局生效，旧局保持原间隔；宿主重载插件时内存中的旧局结束。
开局说明和超时通知使用该局的实际时长；提示、非成语、重复和长度不符的输入均不续时。
本地测试无需 AstrBot：`IdiomGame.create(now=0, answer="一心一意", idle_seconds=150)`。
仅使用可重置的空闲截止时间，不增加整局时长上限。


## 消息展示与猜中者通知

图片必须作为独立消息发送，不能与文字、@ 或其他组件混在同一条消息中，避免聊天客户端折叠图片。
`main.py:_image_messages()` 保留消息链顺序，将每张图片拆成单独消息；普通回复与主动超时通知
复用 `_deliver()` 发送。开局说明独立发送，普通猜测与 `/猜成语提示` 成功时只发送图片。
主动结束、超时和机会用完仅发送简短原因与独立终局图片，不重复写出答案。

群聊猜中时通过 AstrBot 的 `At(qq=event.get_sender_id())` 提及实际猜中者，配文“恭喜猜中！”，
再单独发送终局棋盘；私聊仅保留简短祝贺，不添加群聊 @。
所有发送在聊天锁内依序完成，某条通知失败仍继续尝试发送图片，不回滚或重新扣除次数。
绘图失败时仅提供相应文字错误或已有线索，终局答案仍不退回文字。

回归测试应检查每条含图片的消息只有一个图片组件，提示与进行中猜测无文字组件，
群聊 @ 指向猜中者而非开局者，以及开局、超时、主动结束、失败、成功的图片均独立成条。
真实客户端图片预览与 @ 展示仍需在目标平台联调。
